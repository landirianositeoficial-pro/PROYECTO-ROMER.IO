# 🌌 ROMER.IO - Traductor de Criptolenguaje Digital

¡Bienvenido a **ROMER.IO**! Este proyecto es un traductor web optimizado y de alto rendimiento diseñado para codificar texto en español a un sistema de vocabulario criptográfico único basado en bloques de sílabas y símbolos especiales. 

Desarrollado bajo una estética cyberpunk y optimizado para el manejo masivo de datos, **ROMER.IO** permite transformar documentos extensos de forma instantánea sin comprometer la fluidez del navegador.

---

## 🚀 Características Principales

* **Traducción Ultraeficiente por Bloques:** Diseñado con un bucle de procesamiento lineal optimizado en memoria, capaz de traducir fragmentos de hasta **10,000 palabras** en milisegundos.
* **Interfaz de Cristal Translúcido (Glassmorphism):** Un diseño visual inmersivo que utiliza efectos de desenfoque (`backdrop-filter`) sobre un fondo animado en cascada digital estilo Matrix.
* **Efectos Visuales Interactivos:** Título principal interactivo con animaciones de brillo neón adaptativas al cursor (`hover-glow`).
* **Normalización Inteligente de Caracteres:** Ignora acentos de forma automática, procesa mayúsculas/minúsculas y respeta de forma estricta las reglas nativas para la letra `Ñ` (`YUNÑ`).
* **Herramientas de Productividad:** Incluye un contador dinámico de palabras integrado y un botón inteligente de copiado rápido al portapapeles con retroalimentación visual.

---

## 📝 Reglas de Codificación Incorporadas

El sistema mapea de forma precisa el alfabeto, la numeración y los caracteres de puntuación bajo los siguientes parámetros de sustitución:

* **Abecedario:** Cada letra se convierte en un código silábico único (ej. `A` ➔ `NHEN`, `B` ➔ `FED`, `Ñ` ➔ `YUNÑ`).
* **Estructura Numérica:** Conversión mediante patrones de símbolos lógicos (ej. `0` ➔ `*`, `1` ➔ `··`, `5` ➔ `|'|`).
* **Espaciado Estricto:** Los espacios entre palabras se codifican automáticamente bajo la secuencia `+++`.
* **Interrogación:** Todos los signos de pregunta (`?` y `¿`) se unifican bajo el símbolo `¬`.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de la aplicación.
* **CSS3 Puro:** Diseño responsivo, efectos de iluminación neón y animación de matriz digital sin dependencias externas de imágenes pesadas.
* **Vanilla JavaScript (ES6):** Lógica de procesamiento de strings de alto volumen a través de un mapeo directo indexado en memoria (`Array.join`).

## 💻 Instalación y Uso

No requiere instalaciones complejas ni servidores backend. Al ser una aplicación cliente local, solo debes seguir estos pasos:

1. Clona este repositorio:
   ```bash
   git clone https://github.com
   ```
2. Abre el archivo `traductor.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
3. ¡Pega tu texto y presiona **Traducir Texto**!
